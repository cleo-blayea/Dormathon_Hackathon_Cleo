## What to Check (Specific Instructions for Contractor)

### Priority 1: ATS Contactor and Actuator Mechanism

**This is the most likely cause.** The controller sent the command, but the contactor did not transfer. The zero current (0.0A), ATS position mismatch (commanded GENERATOR, actual UTILITY), and 11 failed transfer confirmations are consistent with unsuccessful transfer.

1. **Manually attempt a transfer** (with generator off and utility disconnected):
   - Command the ATS to transfer to GENERATOR position
   - Observe whether the contactor physically moves
   - If it does not move, check for: mechanical binding, corrosion, debris, broken linkage

2. **Inspect the actuator:**
   - Motor-operated: check motor windings, check for burnt smell, check motor capacitor
   - Solenoid-operated: check solenoid coil resistance, check for mechanical seizure
   - Spring-loaded: check spring tension, check release mechanism

3. **Check control wiring between controller and actuator:**
   - Verify continuity from controller output terminal to actuator input
   - Check for loose, corroded, or broken connections
   - Check any intermediate relays or contactors in the control circuit

### Priority 2: Position Sensor Verification

**Less likely but should be ruled out.**

1. Verify the position sensor reading matches the actual contactor position:

   - If sensor does not match, replace or recalibrate sensor

2. Note: 0.0A current throughout makes sensor fault less likely -- if the contactor had transferred, current would flow even if the sensor reported incorrectly.

### Priority 3: Functional Transfer Test (Before Returning to Service)

**This is critical -- it is what should have been done at the last service.**
