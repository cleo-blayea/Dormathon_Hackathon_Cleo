WorkBuddy Agent

Submit a generator maintenance question below. The dashboard saves it as a request file and shows Awaiting WorkBuddy until a real WorkBuddy agent picks it up. Copy the question into your WorkBuddy workspace to start the investigation. When the agent completes its work, results appear here automatically.

Example Question 1
Is my backup generator ready for the next power outage?
Example Question 2
Why did my generator fail during the last power outage?
How to use: Type or select a question, then click Submit Investigation to save it as a request file. The status shows Awaiting WorkBuddy — the dashboard does not invoke WorkBuddy. Then click Copy Request, open your WorkBuddy AI workspace, and paste the question into the chat. → The agent reads the request, investigates using validate_data.py, fault_investigation.py, and the Flask data API, writes report files to outputs/<request_id>/, and updates the status. → This page auto-refreshes the status every 5 seconds.

Local demonstration only: request/output files exist on this machine. A publicly hosted dashboard will not automatically share these files without additional synchronization.
